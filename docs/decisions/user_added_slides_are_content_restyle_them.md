# Slides the user inserts are reference content — restyle them to match the deck

On 2026-09-30 the user edited an exported deck in PowerPoint (V2), adding a few rough slides (plain Calibri text,
screenshots, a Korean note) among the designed ones, and asked me to "look at V2 and revise". I revised the slides
they had flagged but left their inserted slides in the raw format. The user corrected me: "넣어준거는 참고하라는거지
양식은 통일해야할 것 아니야" — what they put in is material to refer to; the format must be unified.

## How I apply it

- Every slide the user adds (rough text, screenshots, sticky notes) is a content brief: keep its message and its
  images, and rebuild it with the deck's layout, fonts, colours, title position, footer and page number.
- Do this for all inserted slides in the same pass, even the ones the user did not comment on, and say which ones
  were restyled.
- Keep the user's wording as the headline or bullets where it is theirs; add only what the deck needs to read well.
