## 2. Alternative explanation of the same evidence

The same 18 real-only entries also fit a **SimReader model gap**, independent of the missing data. SimReader never lists a structure as a node in its own right. Case and event structures appear only if they have an owner-routed outer face (`OWNER_ROUTED = ("SelectorTunnel","Tunnel")`, `:492`) on that diagram. So even with a correct owners map:
- EventStructure 10153 has no selector. If it has no `Tunnel`-class outer face on 639, it stays real-only.
- Loops get placed only through `loop_parent` (`:537-551`). If owners is missing or incomplete, `loop_parent` returns None and the loop is listed on **every** diagram (`:1672-1676`). Adding loops without a complete owners map would turn 18 real-only entries into many sim-only ones, not zero.

Either way, the missing data is necessary to explain the result, but the file evidence does not show it is sufficient.
