## 4. CHEAPEST discriminating test

## Your three questions

**Q1 — best explanation?** No. A1 is, because A1 has a recorded instance and H has a recorded counter-example in the same line.

**Q2 — does `Close Reference` accept a GObject refnum?** **Yes — and closing one does nothing.** From the NI forum thread: **TheQ (Quentin Alldredge, NI)** — *"Anything that is a GObject … does not need a 'Close Reference'. In fact, if it is used, it does not actually do anything on references to GObjects."* **Rolf Kalbermatter** — *"Any refnum you get with an explicit Open or similar function needs to get closed"*; the VI Server returns the same refnum for the others and Close Reference *"recognize[s] such refnums and simply do[es] nothing on them."* The node accepts the wire. H's mechanism does not exist.

**Q3 — other reasons?** Yes: A1, A2, A3. The `error out`-also-feeding-an-indicator branch is *not* one — that is legal and is a red herring.
