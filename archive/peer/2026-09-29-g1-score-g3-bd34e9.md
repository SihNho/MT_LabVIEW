QUESTION:
In NI-IMAQdx (C function IMAQdxGetImageData, or the LabVIEW IMAQdx Get Image2 VI), what numeric value does each buffer-number mode (Next, Last, BufferNumber, Every, LastNew) have, and which of these modes returns immediately without waiting for a new frame from the camera?

KNOWN ANSWER (verified on the machine / vendor files):
Next = 0, Last = 1, BufferNumber = 2, Every = 3, LastNew = 4. Only Last returns immediately (it returns the newest buffer, possibly the same one again); the other modes block until a buffer not yet returned exists.
KEY POINTS: Next 0, Last 1, BufferNumber 2, Every 3, LastNew 4; only Last does not wait; Last can return the same buffer again

- **A separate set of numbers:** an NI employee explains that buffer numbers use only 24 bits, and the upper bits hold special markers such as "Next, Newest, Oldest, Every, Last New, None" (for example, 4294967294 = "Newest"). **Which mode returns without waiting for a new frame**

- **Last** is the one mode documented as returning right away. The Get Image2 documentation says Last "will not wait for the next buffer but will instead return the last acquired buffer." Next is the default and waits for the next acquired buffer. BufferNumber waits for the exact buffer you ask for (https://www.ni.com/docs/en-US/bundle/ni-imaqdx-vi-ref/page/ni-imaqdx_vi_reference/imaqdx_get_image2.html; my fetch of that page didn't load the text, so this wording comes from search-result excerpts of it).
- **Every** returns the next image you haven't read yet. According to one NI forum answer, it only returns without waiting when that image is already in memory. This isn't an unconditional "never waits" (https://forums.ni.com/t5/Machine-Vision/Buffer-Mode-quot-Next-quot-and-quot-Every-quot-in-IMAQdx-Extract/td-p/4079556).
- **Last New:** the NI article comparing it with Last is https://knowledge.ni.com/KnowledgeArticleDetails?id=kA03q000001DwvoCAC, but I couldn't retrieve its text. From the name, Last New probably waits when no new frame has arrived since your last read, but I haven't confirmed that.
