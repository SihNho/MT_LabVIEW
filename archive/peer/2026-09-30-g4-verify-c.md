## Question

In LabVIEW VI Scripting (VI Server), which property of a Wire object reports whether that wire is broken, and what is that property's unique ID string (the hex ID used when the property is set with Allow Alternate Names = FALSE)? Also say what kinds of wire problems that property does and does not flag.

Search the web and cite the URL of every source you used.

## Answer

Based on web research, here are the answers to your questions regarding LabVIEW VI Scripting and the Wire object:

### 1. Which property reports whether a wire is broken?
The property of a Wire object that reports its broken status is the **"Is Broken?"** property.

### 2. What is that property's unique ID string?
The unique property ID is `6371004` in decimal. When represented as a 4-byte Unique ID string (the hex ID used when setting the property programmatically via a property node with `Allow Alternate Names = FALSE`), the hex ID string is **`006136BC`** (or `0x006136BC` / `6136BC`).

### 3. What kinds of wire problems does it flag and not flag?
*   **What it DOES flag:** It flags standard "broken wire" conditions that violate LabVIEW's dataflow or typing rules and render the block diagram non-executable. This includes type mismatches (e.g., wiring a numeric to a string terminal), class conflicts, or wiring multiple data sources into the same sink.
*   **What it DOES NOT flag:** It **does not flag loose ends**. A wire with a loose end (a wire segment that is not connected to a node terminal on one or both sides) will not return `TRUE` for the "Is Broken?" property. To programmatically address loose ends, developers typically use the `Wire:Clean Up` method to remove them.

### Sources Cited:
*   [LabVIEW Wiki: Property:Wire/Is_Broken?](https://labviewwiki.org/wiki/Property:Wire/Is_Broken%3F) - Lists the specific Property ID as `6371004`.
*   [LabVIEW Wiki: Wire](https://labviewwiki.org/wiki/Wire) - Provides documentation noting that the "Is Broken?" property flags broken wires but explicitly *does not flag loose ends*, and notes that the `Wire:Clean Up` method is used to remove them.
