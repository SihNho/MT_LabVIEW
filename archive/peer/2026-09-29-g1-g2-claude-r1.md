## Question

In LabVIEW, can the 'Enable automatic error handling' option (VI Properties > Execution) of one specific VI be switched off programmatically through VI Server? If so, give the exact class and property name. Is there also a global switch?

Search the web and cite the URL of every source you used.

## Answer

Yes. You can switch it off for one VI through VI Server. There is no documented global switch that you can set programmatically; the only documented global settings are in the Tools » Options dialog.

**Per VI: class VI, property "Automatic Error Handling"**
- The long name is **Automatic Error Handling**, the short name shown on the Property Node is **Auto Err Handling**, and the type is Boolean.
- Wire FALSE to it on a VI reference, for example one from Open VI Reference. It does the same thing as the "Enable automatic error handling" checkbox on the Execution page of VI Properties. ([NI docs](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/properties-and-methods/vi-server/vi/automaticerrorhandling.html), [LabVIEW Wiki](https://labviewwiki.org/wiki/VI_class/Automatic_Error_Handling_property))
- According to the LabVIEW Wiki, it has these limits ([source](https://labviewwiki.org/wiki/VI_class/Automatic_Error_Handling_property)):
  - It works in the editor only, not in the Run-Time Engine and not on real-time targets.
  - It cannot be set while the VI is running.
  - It does not apply to control, global or polymorphic VIs, or to strict type definitions.
  - Remote access is allowed.
- The NI page did not render when I fetched it, so the details above come from the Wiki and the search snippet.
- Setting the property changes the VI in memory. It stays changed only if you save the VI afterwards. That is standard LabVIEW behavior, not something the sources state for this property.

**Global switches (Tools » Options » Block Diagram)**
Search-result snippets from NI's Options page describe two checkboxes, both on by default ([NI Block Diagram Options page](https://zone.ni.com/reference/en-XX/help/372614J-01/lvdialog/block_diagram_options/)). That link now redirects to an unrelated page, so I could not check the full text.
- **"Enable automatic error handling dialogs"**: controls the error dialog for existing VIs that have automatic error handling enabled.
- **"Enable automatic error handling in new VIs"**: only sets the default for new, blank VIs. It does not change existing ones. ([LabVIEW Wiki](https://labviewwiki.org/wiki/Automatic_Error_Handling))

I found no documented Application-class property that sets either option from code.

**Not settled**
- A search snippet mentions an INI key, `EnableAutomaticErrorHandling=False`, in LabVIEW.ini or an executable's .ini, and an `autoerr` token. I did not open or check those pages, and no NI documentation I found confirms either one. ([Hampel Software INI keys](https://dokuwiki.hampel-soft.com/kb/labview/ini-keys), [NI forum thread](https://forums.ni.com/t5/LabVIEW/How-to-disable-internal-error-handling/td-p/1802206))
- An NI Idea Exchange post asks for a way to turn automatic error handling on or off for all project items at once. That suggests there is no built-in bulk switch, and the usual workaround is a VI Scripting loop that sets the per-VI property. ([Idea Exchange](https://forums.ni.com/t5/LabVIEW-Idea-Exchange/Ability-to-enable-or-disable-Automatic-Error-Handling-for-all/idi-p/4392260), [LabVIEW Wiki](https://labviewwiki.org/wiki/Automatic_Error_Handling))
