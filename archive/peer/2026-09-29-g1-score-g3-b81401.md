QUESTION:
In NI-IMAQdx (C function IMAQdxGetImageData, or the LabVIEW IMAQdx Get Image2 VI), what numeric value does each buffer-number mode (Next, Last, BufferNumber, Every, LastNew) have, and which of these modes returns immediately without waiting for a new frame from the camera?

KNOWN ANSWER (verified on the machine / vendor files):
Next = 0, Last = 1, BufferNumber = 2, Every = 3, LastNew = 4. Only Last returns immediately (it returns the newest buffer, possibly the same one again); the other modes block until a buffer not yet returned exists.
KEY POINTS: Next 0, Last 1, BufferNumber 2, Every 3, LastNew 4; only Last does not wait; Last can return the same buffer again

**Which mode returns without waiting**

- **Last:** NI's documentation says "the driver does not wait for the next buffer but instead returns the last acquired buffer." I read this wording in the search-result summaries ([documentation.help Get Image Data VI](https://documentation.help/NI-IMAQdx-VI/IMAQdx_Get_Image_Data.html)) and a quote in the [NI forum thread on Next vs. Every](https://forums.ni.com/t5/Machine-Vision/Buffer-Mode-quot-Next-quot-and-quot-Every-quot-in-IMAQdx-Extract/td-p/4079556). I couldn't open the page itself (HTTP 403).
- **Next:** waits for the next acquired buffer ([same](https://documentation.help/NI-IMAQdx-VI/IMAQdx_Get_Image_Data.html)).
- **BufferNumber:** "specifies an exact buffer number to wait for," so it blocks until that buffer exists (search-result summary of the same NI docs).
- **Every:** one forum post says it "returns all sequential images in memory," so buffers that are already queued come back quickly ([NI forum](https://forums.ni.com/t5/Machine-Vision/Buffer-Mode-quot-Next-quot-and-quot-Every-quot-in-IMAQdx-Extract/td-p/4079556); also [this thread](https://forums.ni.com/t5/Machine-Vision/Trying-to-understand-how-the-buffers-work-in-Imaqdx-aquisition/td-p/3986038)). That comes from forum users, not NI documentation. Nothing I found says what Every does when no un-read buffer is left, so I can't call it non-blocking.
- **LastNew:** NI has a knowledge-base article on exactly this, "[IMAQdx Get Image 2 VI: Buffer Number Mode 'Last' And 'Last New' Differences](https://knowledge.ni.com/KnowledgeArticleDetails?id=kA03q000001DwvoCAC&l=en-US)."
