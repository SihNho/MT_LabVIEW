## Question

In LabVIEW, can the 'Enable automatic error handling' option (VI Properties > Execution) of one specific VI be switched off programmatically through VI Server? If so, give the exact class and property name. Is there also a global switch?

Search the web and cite the URL of every source you used.

## Answer

**Answer: yes, you can do this for a specific VI through VI Server.**

- **Class:** VI class. Open a reference to the target VI, for example with Open VI Reference, and wire it to a Property Node.
- **Property:** `Automatic Error Handling` (short name `Auto Err Handling`), in the Execution category. It's a Boolean and you can read and write it. Write FALSE to switch it off.
- **Limits:** You can't change it while that VI is running. It's marked as not available in the LabVIEW Run-Time Engine, which doesn't support automatic error handling anyway, so this is a development-environment setting. (LabVIEW Wiki property page; NI's reference page for the same property is listed below, but I couldn't load its content.)

**Global switch: only for new VIs, as far as I could confirm.**

- **Tools » Options » Block Diagram » "Enable automatic error handling in new VIs"** only sets the default for new, blank VIs. It doesn't change VIs that already exist. (LabVIEW Wiki; LabVIEW Artisan blog)
- **No built-in switch for existing VIs.** An NI Idea Exchange post asks for a way to turn it on or off for all VIs in a project, which suggests none exists. The usual workaround is to loop over the VIs and set the property above on each one.
- **Unconfirmed:** From memory, the same Options page also has an "Enable automatic error handling dialogs" checkbox that suppresses the dialogs everywhere. None of the sources I found mention it, and I couldn't find a LabVIEW.ini key for either option. Check the Options dialog in your LabVIEW version.
