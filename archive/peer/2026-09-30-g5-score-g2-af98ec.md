QUESTION:
In LabVIEW, can the 'Enable automatic error handling' option (VI Properties > Execution) of one specific VI be switched off programmatically through VI Server? If so, give the exact class and property name. Is there also a global switch?

KNOWN ANSWER (verified on the machine / vendor files):
Yes: the VI class property 'Automatic Error Handling' (a writable Boolean on a VI reference) turns it off for that VI. A global alternative is the labview.ini key EnableAutomaticErrorHandling=False.
KEY POINTS: VI class property Automatic Error Handling; writable; global ini key EnableAutomaticErrorHandling

Yes. You can switch it off for one VI through VI Server. There is also a global switch in Tools > Options, but it works differently from the per-VI setting.

**1. Per-VI, through VI Server: yes**

- **Class:** VI class (wire it a VI reference, for example from Open VI Reference)
- **Property:** `Automatic Error Handling` (short name `Auto Err Handling`)
- **Type:** Boolean, read/write. TRUE turns automatic error handling on; write FALSE to turn it off.
- **Limits:**
  - The target VI can't be running when you write the property; it doesn't have to be idle.
  - It isn't available in the Run-Time Engine or on a real-time OS.
  - It doesn't apply to control VIs, global VIs, polymorphic VIs or strict type definitions.
  - Remote access is allowed.

Source: https://labviewwiki.org/wiki/VI_class/Automatic_Error_Handling_property

Setting it through VI Server doesn't save the VI. That's my own inference, not something the source says: to make the change permanent you would normally also save the VI, for example with the Save:Instrument method.

**2. Global switch: yes, but it's not one VI Server property**

The Block Diagram page of Tools > Options has two related checkboxes:

- **"Enable automatic error handling in new VIs"** only sets the default for VIs you create from now on. It doesn't change VIs that already exist.
- **"Enable automatic error handling dialogs"** is the real global switch. If you uncheck it, LabVIEW won't suspend execution or show the error dialog, even for VIs that still have automatic error handling turned on. It is checked by default.

Sources:
- https://zone.ni.com/reference/en-XX/help/372614J-01/lvdialog/block_diagram_options/ (I only have this text from a search result snippet. The link now redirects to an unrelated NI page, so I couldn't read the full page.)
- https://forums.ni.com/t5/LabVIEW-Idea-Exchange/Ability-to-enable-or-disable-Automatic-Error-Handling-for-all/idi-p/4392260 (a commenter says "You can turn off AEH globally for LabVIEW in the options" and points to the dialogs checkbox)

**3. No built-in "set it on every VI" command**

That NI Idea Exchange post asked for a project-level way to turn automatic error handling on or off for all VIs at once. NI declined it on 30 Sep 2024 and pointed people to a third-party "Property Inspector" toolkit instead. Without that, you'd loop over your VIs and write the property above on each one.
