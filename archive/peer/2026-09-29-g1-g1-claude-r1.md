## Question

In LabVIEW VI Scripting (VI Server), which property of a Wire object reports whether that wire is broken, and what is that property's unique ID string (the hex ID used when the property is set with Allow Alternate Names = FALSE)? Also say what kinds of wire problems that property does and does not flag.

Search the web and cite the URL of every source you used.

## Answer

I found the property, but I couldn't confirm the hex ID, and no source says which kinds of wire problems it flags.

**The property.** It is **"Is Broken?"** on the Wire class. Its short name and data name are both "Broken?". It is a read-only Boolean that belongs to VI Scripting. The only description I found is: *"Returns TRUE if the wire is broken or in a bad state."* It isn't available in the Run-Time Engine or on Real-Time OS. — [LabVIEW Wiki: Wire class/Is Broken? property](https://labviewwiki.org/wiki/Wire_class/Is_Broken%3F_property)

**The hex ID is not confirmed.** The tool I used to read that wiki page returns a summary, not the raw page. It reported the ID as "6371004 (hex: 0x61068C)", but those two numbers don't match: 6371004 in hex is 0x6136BC, and 0x61068C in decimal is 6358668. At least one of them was misread. I also found nothing that ties either number to the ID shown when Allow Alternate Names = FALSE. NI's official API reference has pages for other Wire properties, like [Terminals[]](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/properties-and-methods/vi-server/generic/gobject/wire/terminals.html) and [Wire Width](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/properties-and-methods/vi-server/generic/gobject/wire/wirewidth.html). I couldn't find a page for Is Broken?, and my guessed URL for one returned no content. To settle it, read the wiki page yourself, or open the property in LabVIEW with Allow Alternate Names turned off and look at the ID it shows.

**What it does and doesn't flag is not documented** in any source I found. The description says only "broken or in a bad state", and the wiki page gives no further detail on what it covers. Here is some related context, but none of it describes this property:
- Broken wires usually come from incompatible data types; see [NI KB: Wire Class Conflict and Broken Wires](https://knowledge.ni.com/KnowledgeArticleDetails?id=kA00Z0000019XS0SAM&l=en-US).
- According to a forum summary, a bad sink breaks only the branch that leads to it, and Ctrl+B handles dangling (loose) ends separately; see [NI Idea Exchange: Break bad wire branches](https://forums.ni.com/t5/LabVIEW-Idea-Exchange/Break-bad-wire-branches-not-the-entire-wire/idi-p/3190706/page/4).
- There is also a separate VI method called [Block Diagram:Remove Bad Wires](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/properties-and-methods/vi-server/vi/removebadwires.html).

Whether Is Broken? returns TRUE for loose ends, for a single bad branch, or only for type conflicts isn't documented anywhere I looked. Testing it in LabVIEW is the only way I know to find out.
